# ☕ Paik's Coffee Clone & Extension (Full-Stack)
> 빽다방 공식 웹사이트 클론 코딩 및 장바구니 주문 기능 확장 프로젝트

- **개발 기간:** 2022년 7월 ~ 10월
- **개발 인원:** 4인 (프론트 3명, 백 1명)
- **담당 역할:** 프론트엔드 개발 (메인, 메뉴, 장바구니 UI 및 핵심 로직 전담)

---

## 🛠 기술 스택
- **Frontend:** React (v18), React Router DOM (v6), Styled-components, React-Cookie, Axios
- **Backend/DB:** Node.js (Express), MySQL, Sequelize ORM (협업)

---

## 🎯 주요 구현 기능 및 기여도

### 1. 회원 연동형 장바구니 시스템 (100% 전담)
- **실시간 금액 계산:** 핫/아이스, 샷 추가 등 옵션 선택 및 수량 변경에 따른 실시간 총 금액 계산 로직 구현
- **중복 상품 예외 처리:** 동일 옵션 상품 재추가 시, 행 추가 대신 기존 상품의 수량이 누적되도록 처리
- **API 연동:** 유저 고유 ID 기반의 장바구니 CRUD 백엔드 API 연동 (`Axios` 활용)

### 2. UI 및 컴포넌트 설계
- 프론트 팀원들과 UI 가이드 수립 후 `styled-components`로 재사용 컴포넌트 구현
- `react-router-dom(v6)` 기반의 SPA 라우팅 구조 설계

### 3. 개발 환경 최적화
- `concurrently` 및 `http-proxy-middleware` 설정을 주도하여 명령어 하나로 프론트/백 서버 동시 구동 및 로컬 CORS 이슈 해결

---

## 👥 협업 및 성장 포인트
- **역할 분담:** 프론트 3인 협업 시 페이지/기능 단위로 역할을 명확히 나누어 Git 충돌 최소화
- **API 조율:** 백엔드 개발자와 장바구니 데이터 구조(JSON)를 함께 정의하며 풀스택 데이터 흐름 이해
- **환경 설정:** 프록시 및 스크립트 최적화를 직접 구성하며 웹 애플리케이션 전체 구조에 대한 시야 확장
